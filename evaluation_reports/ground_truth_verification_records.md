## 1. Audit Methodology

Every citation emitted by CodeMind AI across all 60 blind evaluation questions was verified against the actual filesystem code on disk.
The verification script `scratch/verify_ground_truth_and_score.py` performed automated static checks:
1. **File Existence**: Confirmed the cited relative path exists within the repository root directory.
2. **Line Range Validity**: Read the physical file lines and verified `1 <= start_line <= end_line <= total_lines`.
3. **Content Alignment**: Verified that the targeted symbol, function, class, or structure exists within or overlaps the cited span.
4. **Hallucination Detection**: Checked for fabricated functions, invented modules, or non-existent files.
