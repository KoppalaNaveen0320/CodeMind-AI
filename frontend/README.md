# Frontend

This directory is designated for the frontend UI assets.

- `templates/`: HTML templates and exported Figma UI pages (e.g., `dashboard.html`).
- `static/css/`: Stylesheets and design tokens.
- `static/js/`: Client-side JavaScript scripts.
- `static/assets/`: Static media, icons, and fonts.

*Note: Implementation has not started. UI files will be placed here in subsequent steps.*
