HIGH CWE-798 Secrets

Hardcoded signing fallback

src/auth/token.service.ts:22
20const configuredSecret = env.JWT_SECRET;
21const signingSecret = configuredSecret ||
22 'development-secret-change-me';
23return jwt.sign(payload, signingSecret);

Why this matters

If the environment variable is missing in a deployed environment, tokens are signed with a value present in source control. An attacker who knows the fallback could forge valid sessions.

Recommended remediation

Remove the fallback and fail application startup when JWT_SECRET is absent. Store the secret in the deployment secret manager and rotate any key used by an affected environment.
