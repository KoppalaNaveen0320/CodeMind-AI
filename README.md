# CodeMind AI

CodeMind AI is an intelligent repository understanding and change-impact prediction system using Hybrid RAG and Knowledge Graphs.

## Project Structure Overview

```text
codemind-ai/
├── frontend/
│   ├── templates/          # HTML templates & UI pages (clean URLs)
│   ├── static/             # Static UI assets (css, js, assets)
│   └── README.md
├── backend/
│   ├── app/                # FastAPI application core & modules
│   ├── migrations/         # Database migrations (Alembic)
│   ├── tests/              # Test suites (400+ pytest tests)
│   ├── requirements.txt    # Python dependencies
│   ├── .env.example        # Environment variable definitions
│   └── README.md
├── docs/                   # Architecture documentation & deployment guides
├── .gitignore
└── README.md
```
